# JPMorgan Chase & Co. - Software Engineering Lite
## Task 1: Stock Price Data Feed Analysis

### Overview
Your task is to implement a Python utility script that interfaces with financial stock market data feeds. 

### Requirements:
1. Parse stock quotes containing `stock`, `top_bid_price`, `top_ask_price`, and `timestamp`.
2. Compute the correct stock price using `(bid_price + ask_price) / 2`.
3. Compute the ratio of two stock prices (avoiding divide-by-zero errors).
4. Implement sample unit tests verifying calculation accuracy and edge cases.
5. Create a comprehensive README.md explaining the implementation and how to execute the code.
