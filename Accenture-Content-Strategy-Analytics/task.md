# Accenture - Data Analytics & Strategy
## Task: Social Buzz Content Engagement & Sentiment Analytics Pipeline

### Business Context
A rapidly growing social media client (Social Buzz) needs actionable insights from 7 disparate datasets (Reactions, Content, ReactionTypes) totaling over 100,000 interactions to guide their IPO strategy.

### Technical Requirements
1. Build an automated data cleaning and harmonization pipeline that handles missing values, inconsistent categories, and outliers.
2. Merge relational datasets using appropriate join strategies (`content_id`, `reaction_type`).
3. Calculate aggregate engagement scores across content categories and rank top 5 performing segments.
4. Output structured analytical summaries in CSV and JSON formats, ready for executive reporting.
5. Write unit tests validating data integrity post-transformation, and document executive insights in README.md.
